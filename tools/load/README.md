# اختبار الضغط

يشغّل عددًا من المتداولين معًا: كل واحد يفتح اتصال البث المباشر ويرسل أمرًا كل 1–3 ثوانٍ ويقرأ محفظته كل 10 ثوانٍ.

1. أنشئ الحسابات واحفظ الرموز: `php artisan tinker --execute="$(cat tools/load/users.php)" | grep TOK > /tmp/load/tokens.txt`
2. شغّل: `SECONDS=60 node tools/load/load.mjs`

يطبع زمن استجابة الواجهة، والزمن من إرسال الأمر إلى وصول نتيجته، وحالات الأوامر وأسباب الرفض.
